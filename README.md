# Análise Exploratória de Dados de Produtividade

Projeto desenvolvido como parte da disciplina de Ciência de Dados, utilizando Python para exploração, organização e visualização de dados relacionados à produtividade de funcionários.

## Sobre o projeto

A análise utiliza um conjunto de dados com 230 observações e variáveis relacionadas a características demográficas e profissionais, como idade, gênero, departamento, salário, horas trabalhadas, produtividade, satisfação, tempo na empresa, cursos realizados e trabalho em home office.

A partir desses dados, foi criada uma variável binária de produtividade baseada na mediana do indicador original.

## O que foi realizado

- classificação das variáveis;
- tabelas de frequência;
- visualizações das variáveis qualitativas;
- tabelas de contingência;
- cálculo de proporções;
- exploração da relação entre departamento e nível de produtividade.

## Tecnologias utilizadas

Python · Pandas · NumPy · Matplotlib · Seaborn
